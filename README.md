## 🚀 Projects

### [GPU Cloud Deal Desk](https://github.com/shravankumaar31/gpu-deal-desk)
`HubSpot · Python · Deal Desk · Quote-to-Cash · Data Quality`

A working quote-to-cash deal desk for a GPU cloud company — the operating process, not a report on it. A quote engine that **blocks rather than guesses** when a contract is incomplete, an approval matrix calibrated against 44 real deals, a 3-Day Rule tracker that names who each stalled contract is waiting on, and a hygiene audit that found 23 problems and could safely auto-fix exactly one.

Includes a [decisions log](https://github.com/shravankumaar31/gpu-deal-desk/blob/main/docs/decisions.md) of all 25 judgment calls — including the approval matrix that first sent 36% of deals to the CEO, and the pause rule that turned out to be bypassable in one command.
